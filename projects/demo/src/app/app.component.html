Typed columns

Pass columns and data. Each column key must be a field on the row type, so a typo fails at compile time. label is the header text. Cells print row[key] unless you add a template. 

[columns]="columns"
[data]="users"

Custom cells

Use ng-template didiCell="key" to replace a column’s default text. let-row is the row object. Columns without a template still show the field value. Here Email is a mailto link and Role is a badge. 

<ng-template didiCell="email" let-row>
  <a [href]="'mailto:' + row.email">{{ row.email }}</a>
</ng-template>
{{ row.email }} {{ row.role }}

Empty & loading

[loading]="true" replaces rows with the loading state. If loading is off and data is empty, the empty state is shown. Put content in didiEmpty / didiLoading to customize. Leave those templates empty (or omit them) to use emptyMessage (No data) and loadingMessage (Loading...). 

[loading]="loading"
<ng-template didiEmpty>No users to show.</ng-template>
<ng-template didiLoading>Loading users…</ng-template>
No users to show. Loading users…

Sorting

Set [sortable]="true" to make headers clickable. Clicks cycle asc → desc → original order. The current state is sort: {{ '{' }} key, direction {{ '}' }} or null when unsorted. Bind [sort] and (sortChange) (or [(sort)]) if the parent needs it. Set sortable: false on a column to keep that header static. Email is turned off below.

Current sort: {{ headerSort ? headerSort.key + ' / ' + headerSort.direction : 'null' }} 

[sortable]="true"
[sort]="sort"
(sortChange)="onSortChange($event)"

{{ '{' }} key: 'email', label: 'Email', sortable: false {{ '}' }}

Row click & selection

(rowClick) always fires when you click a row (not a link or checkbox). [selectable]="'single'" keeps one highlighted row. Click it again to clear. [selectable]="'multiple'" adds checkboxes and a header “select this page” box. Bind [(selected)] for the chosen rows. identityKey compares rows by a field (here email) so selection still works if objects are recreated.

Last click: {{ clicked ? clicked.name : 'none' }} · Selected: {{ selectedNames ? selectedNames : 'none' }} 

(rowClick)="onRowClick($event)"
[selectable]="selectionMode"
[(selected)]="selected"
identityKey="email"

Sticky header

[stickyHeader]="true" keeps column titles visible while the body scrolls. Set maxHeight so the table itself scrolls (otherwise the page would have to be tall enough). caption is a hidden table name for screen readers. Sort buttons also announce the current direction. 

[stickyHeader]="true"
maxHeight="220px"
caption="People"

Pagination

Set [pageSize] to show a pager. Switch modes with [pagination]="'client'" or [pagination]="'server'".

  • Client — pass the full list. The table sorts and slices it. You do not need total.
  • Server — pass only the current page plus [total] from the API. Reload data on (pageChange) and (sortChange). This demo uses a fake 350ms API. 
[pagination]="pagination"
[pageSize]="3"
[page]="page"
[total]="total"
(pageChange)="onPageChange($event)"
(sortChange)="onSortChange($event)"

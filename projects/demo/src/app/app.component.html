Typed columns

Pass columns and data. Each column key must be a field on the row type, so a typo fails at compile time. label is the header text. Cells print row[key] unless you add a template. 

[columns]="columns"
[data]="users"

Striped rows

[striped]="true" paints every other row a near-white tint so you can follow a line across the table. Hover is the same color, just a little stronger. 

[striped]="true"

Customization

ng-template didiCell="key" replaces a cell: buttons, icons, colors, and custom formats all go there. let-row is the row, let-value="value" is the cell value (including nested paths). format on a column formats without a template. didiHeader="key" replaces the header label. Nested data uses dotted keys such as address.city.

Last edit: {{ edited ? edited : 'none' }} 

{{ '{' }} key: 'address.city', label: 'City' {{ '}' }}
{{ '{' }} key: 'salary', label: 'Salary', format: (v) => '$' + v {{ '}' }}

<ng-template didiHeader="name">Name ★</ng-template>
<ng-template didiCell="status" let-row>...</ng-template>
Name ★ 👤 {{ row.name }} {{ row.status }}

Empty & loading

[loading]="true" replaces rows with the loading state. If loading is off and data is empty, the empty state is shown. Put content in didiEmpty / didiLoading to customize. Leave those templates empty (or omit them) to use emptyMessage (No data) and loadingMessage (Loading...). 

[loading]="loading"
<ng-template didiEmpty>No users to show.</ng-template>
<ng-template didiLoading>Loading users…</ng-template>
No users to show. Loading users…

Sorting

[sortable]="true" makes headers clickable. Strings, numbers, and dates are detected automatically, or set sortType to 'string', 'number', or 'date'. Use compare for a custom order (Rank below is junior → mid → senior). Server paging does not sort locally; handle it in (sortChange). [multiSort]="true" stacks columns: click Name, then Age.

Current sort: {{ sortLabel }} 

[sortable]="true"
[multiSort]="true"
sortType: 'number'
compare: (a, b) => rankOrder[a] - rankOrder[b]

Row click & selection

(rowClick) always fires when you click a row (not a link or checkbox). [selectable]="'single'" keeps one highlighted row. Click it again to clear. [selectable]="'multiple'" adds checkboxes and a header “select this page” box. Bind [(selected)] for the chosen rows. identityKey compares rows by a field (here email) so selection still works if objects are recreated.

Last click: {{ clicked ? clicked.name : 'none' }} · Selected: {{ selectedNames ? selectedNames : 'none' }} 

(rowClick)="onRowClick($event)"
[selectable]="selectionMode"
[(selected)]="selected"
identityKey="email"

Sticky header

[stickyHeader]="true" keeps column titles visible while the body scrolls. Set maxHeight so the table itself scrolls (otherwise the page would have to be tall enough). caption is a hidden table name for screen readers. Sort buttons also announce the current direction. 

[stickyHeader]="true"
maxHeight="220px"
caption="People"

Sticky columns

Pin the identifier on the start and actions on the end. Middle columns scroll. pinned: true or 'start' freezes from the left; pinned: 'end' freezes from the right. You can pin more than one column on each side. 

{{ '{' }} key: 'name', label: 'Name', pinned: true {{ '}' }}
{{ '{' }} key: 'status', label: 'Status', pinned: 'end' {{ '}' }}
{{ '{' }} key: '_actions', label: 'Actions', pinned: 'end' {{ '}' }}

Pagination & search

Set [pageSize] to show a pager. [pageSizeOptions] adds a rows-per-page control. The pager has First, Previous, Next, and Last so you can jump to either end. Switch pagerNav between 'label' (First / Previous) and 'icon' (« ‹ › »). Screen readers still hear the word labels. Switch modes with [pagination]="'client'" or [pagination]="'server'". Cards uses responsive="stack" in a phone-width frame so you can try the mobile pager without shrinking the window.

  • Client — pass the full list. The table searches, sorts, and slices it. You do not need total.
  • Server — pass only the current page plus [total] from the API. Reload data from (queryChange) (or the individual page/sort/search events). This demo uses a fake 350ms API.
  • Page state — sort and search reset to page 1 by default. Keep page sets [resetPageOnSort] and [resetPageOnSearch] to false so the current page is kept (and clamped if it is now past the last page). 
[searchable]="true"
[pageSizeOptions]="[3, 5, 10]"
responsive="stack"
(queryChange)="onQueryChange($event)"

{{ row.email }} {{ row.role }}

Collapse columns

Wide tables can hide extra columns. Set [columnCollapse]="true" for a Columns menu and a hide control on each header. After you hide some, Show all brings every column back in one click. hidden: true starts a column collapsed. collapsible: false keeps a column always visible (Name below). Bind [(hiddenColumns)] if the parent should remember what is hidden. 

[columnCollapse]="true"

{{ '{' }} key: 'name', label: 'Name', collapsible: false {{ '}' }}
{{ '{' }} key: 'city', label: 'City', hidden: true {{ '}' }}

Responsive / mobile

A wide table is hard to use on a phone. responsive="stack" turns each row into a labeled card when the table is narrower than breakpoint (default 640px). responsive="scroll" keeps the grid and scrolls sideways. [stickyFirstColumn]="true" pins the first column while scrolling. Set pinned: true on any other columns you want frozen as well. Set hideOnMobile: true on a column to drop it automatically in the narrow view (Team and City below). Pagination stays under the cards: range and rows-per-page on one row, First / Previous / Next / Last on the next. 

responsive="stack"
breakpoint="640px"
[pageSize]="3"
[pageSizeOptions]="[3, 5]"
[stickyFirstColumn]="true"

{{ '{' }} key: 'city', label: 'City', hideOnMobile: true {{ '}' }}

Theming

Default is inherit: the table uses the page font and currentColor, so it matches an existing app. Set theme="light", dark, teal, warm, or compact for a packaged look. [themePicker]="true" puts a theme select in the table toolbar next to search. Leave it off if the app should pick the theme, not the end user. 

[themePicker]="true"
[(theme)]="tableTheme"
